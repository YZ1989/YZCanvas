## 请在 Windows 桌面预览版验证

- 安装与启动：标题显示 YZCanvas，深浅主题、窗口最小化/最大化/关闭正常；缺少 WebView2 的机器需要联网安装运行时。
- 本地数据：应用使用独立存储空间；重新启动后画布、图片与视频恢复，不覆盖原 TDCanvas 数据。
- 图片：导入、裁剪、绘制/编辑、下载和原生另存为；实际 API 生成、参考图编辑、重试与取消。
- 视频：导入、播放、保存、文生视频和图生视频；空闲节点仅预载元数据。
- 轻量范围：界面无 Agent、ComfyUI、插件管理和新建音频入口；旧项目音频仍可读取；未知扩展节点保留原始数据但不能执行。
- 项目导入导出：沿用 TDCanvas 格式，未知节点与连线能往返保存。
- 性能：100 张图片、多视频、大尺寸图片和长时间运行的内存与响应尚未测量。
